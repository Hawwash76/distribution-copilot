# Prompts

Prompt templates live here, grouped by capability. Keep each prompt in its own
file and keep prompt *content* separate from application logic.

```
prompts/
├── discovery/         # finding relevant online conversations
├── scoring/           # ranking opportunities by relevance/intent
├── reply-generation/  # drafting context-aware replies
└── risk-analysis/     # flagging risky or off-brand replies
```

> Structure only — no prompts are implemented yet.
